# Demo script (2–3 minutes)

1. Introduce this as a prototype that reads printed pack details and compares them with a fictional registry record.
2. Show a demo pack and point out batch number, expiry and manufacturer.
3. Run OCR and display extracted fields and confidence.
4. Compare the extracted fields against the registered record.
5. Show a matching sample, then the doctored-expiry sample and the mismatch explanation.
6. Show an intentionally blurry photo returning `unreadable`.
7. State the limitation clearly: **This check confirms a pack matches a registry record. It does not test the medicine inside.**

Never describe a `match` result as proof that a medicine is genuine, safe, or effective.
